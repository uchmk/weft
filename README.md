# weft

Markdown 専用エディター。キーだけで見出し・リスト・表などの構造を組み替え、日本語 IME に強く、フォルダー（vault）も扱う。
kura で `.md` に Enter を押したときに開く（単体でも起動できる）。

- **構造をキーで操作する**: 段落・リスト項目・節（子の見出しごと）の上下の入れ替え、節の昇格・降格、リストの階層、タスクの切り替え、番号の振り直し、表の整形とセルの移動。
- **日本語 IME を最優先**: 変換中にカーソルや選択が飛ばない。変換中は補完を開かず、確定の Enter をコマンドに使わない。全角スペースと意図しないハード改行を控えめに示す。
- **vault を扱う**: `[[…]]` の補完、バックリンク、全文検索、リネームへの追従（フェーズ 5）。
- **割り切り**: プラグイン・マクロ・Vim 風のモード・複雑な WYSIWYG は持たない。汎用の編集は 1 キーで `$EDITOR` へ渡す。

設計は [docs/design.md](docs/design.md)、やることは [TODO.md](TODO.md)。

uchmk のアプリ。共通の部品は [ito](https://github.com/uchmk/ito) を使う。
